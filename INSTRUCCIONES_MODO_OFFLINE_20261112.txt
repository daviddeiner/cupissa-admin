CUPISSA — MODO SIN CONEXIÓN (12/11/2026)

NO NECESITA SQL NI EDGE FUNCTIONS ADICIONALES.

CLIENTES:
- Se precargan páginas, scripts y estilos. Un primer acceso con internet es obligatorio.
- Las consultas del catálogo y fotografías públicas ya descargadas pueden verse sin conexión.
- Las páginas no visitadas pueden abrir si su estructura se precargó, pero NO se pueden consultar productos/medios que nunca se hayan descargado.
- No se pueden confirmar compras, pagos, OTP, cuentas, inventario o precios nuevos sin internet.

ADMIN:
- Se conservan páginas y recursos descargados. Las lecturas Supabase consultadas antes se respaldan localmente.
- Algunas ediciones simples (PATCH de productos, pedidos y clientes, por ID, sin estados ni finanzas) se dejan EN COLA si falla la red, con aviso, y se reintentan al reconectar.
- No se admite crear usuarios/productos/pedidos nuevos, subir imágenes, cambiar ENTREGADO, borrar registros ni registrar créditos/cuotas sin internet, porque requieren validación y sincronización seguras.
- Operaciones pendientes no están confirmadas; verificar en Supabase después de reconectar.
- Para protección de privacidad, cierre sesión en el administrador cuando deje de usar el dispositivo; los datos cacheados de lecturas se borran entonces.
- La cola de ediciones guarda temporalmente datos de solicitud, incluida sesión de acceso; usar únicamente dispositivos confiables y no compartir perfiles del navegador.

PUBLICACIÓN: reemplazar todos los archivos del ZIP en los respectivos proyectos GitHub Pages, no solo service-worker.js. Probar primero en ventana normal online, cargar catálogo y admin, luego DevTools > Network > Offline.

ADVERTENCIA: el navegador puede expulsar la caché cuando falta almacenamiento. No es posible garantizar «absolutamente todos» los datos o acciones sin precarga ni backend local; no se sustituye Supabase ni Wompi.
