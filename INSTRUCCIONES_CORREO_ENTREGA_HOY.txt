CUPISSA — AVISO AUTOMÁTICO DE ENTREGA DEL DÍA

Esta versión parte del ZIP ORIGINAL cupissa-admin(10).zip.
No modifica los filtros de pedidos ni sustituye las Edge Functions anteriores.

1. En Supabase > Edge Functions, crea una nueva función llamada exactamente:
   cupissa-recordatorio-entrega
   Pega el contenido de supabase/functions/cupissa-recordatorio-entrega/index.ts.
   Puedes dejar Verify JWT activado para la clave JWT antigua service_role.
   El código valida adicionalmente la credencial con Supabase Auth Admin API,
   que solo acepta permisos service_role. No modifica cupissa-emails.

2. En Supabase > Edge Functions > Secrets, comprueba que existan:
   SUPABASE_URL y SUPABASE_SERVICE_ROLE_KEY (las provee Supabase),
   CUPISSA_MAILER_URL y CUPISSA_MAILER_SECRET (idénticas a cupissa-emails).

3. En Supabase > SQL Editor > New query:
   a) Guarda en Supabase Vault la clave service_role JWT del mismo proyecto:
      select vault.create_secret('AQUI_TU_SERVICE_ROLE_JWT','cupissa_delivery_service_role');
      Sustituye el texto AQUI_TU_SERVICE_ROLE_JWT por la clave JWT real.
      NO pongas el valor en código de GitHub ni en archivos públicos.
   b) Ejecuta supabase/CONFIGURAR_RECORDATORIOS_ENTREGA.sql.

4. Para ejecutar hoy mismo a cualquier hora, desde SQL Editor:
   select public.cupissa_disparar_avisos_entrega(true) as solicitud_en_cola;
   El resultado numérico es el ID de solicitud, no la confirmación de correos.
   Comprueba los envíos con:
   select * from public.cupissa_avisos_entrega order by reservado_en desc limit 100;
   Y revisa los Logs de la Edge Function.
   IMPORTANTE: la versión 2 de esta Edge corrige el error 401 causado por
   comparar literalmente claves distintas en los encabezados. Si ya instalaste
   la versión anterior, vuelve a desplegar SOLO cupissa-recordatorio-entrega.
   No necesitas repetir el SQL de creación de tablas ni guardar otra clave.

5. Automático diario: cron '0 12 * * *' en UTC = 7:00 a. m. Bogotá.
   No requiere mantener el administrador abierto.
   Se revisa public.pedidos_web.fecha_entrega = fecha actual de Colombia.
   Se excluyen estados ENTREGADO y CANCELADO. Los correos se resuelven
   desde clientes_web, clientes o el correo guardado en el pedido.
   Un pedido solo recibe un aviso por fecha, aunque se ejecute otra vez.

NOTA: Si hay pedidos con fecha de entrega almacenada en una columna diferente
de fecha_entrega, hay que adaptar esa consulta a la estructura real de Supabase.
